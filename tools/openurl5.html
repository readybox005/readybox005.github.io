2. 扩展的 content script 在阿里页面内部执行，window.scrollBy() 同源调用，无跨域限制
3. opener 通过 postMessage 向子窗口发送滚动指令，扩展接收并执行

5. 全自动：安装扩展后无需任何手动操作，每次打开阿里页面自动注入滚动能力

⚠️ 使用说明：
1. 首先安装配套 Chrome 扩展（见上方橙色提示）
2. 安装扩展后，每次打开阿里商品页面，扩展会自动注入滚动脚本
3. 本工具通过 postMessage 向阿里页面发送滚动指令，无需手动操作
4. 全自动流程：打开页面 → 等待加载 → 停留1-3秒 → 自动滚动 → 关闭
5. 如果未安装扩展，滚动功能会自动降级为"仅停留不滚动"模式
